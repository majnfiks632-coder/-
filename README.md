# ДубинаОС

Микроядерная операционная система с упором на безопасность. Полностью на русском языке — от загрузчика до пользовательских приложений.

## Главные идеи

- **Микроядро**: ядро занимается только потоками, адресными пространствами, IPC и базовыми прерываниями. Всё остальное — пользовательские службы (память, разрешения, файлы, окна, драйверы).
- **Приложения «в банке»**: программа сама по себе может выполнять только вычисления на ЦПУ/ГПУ. Любое взаимодействие с внешним миром (файлы, сеть, экран) — только через явно выданные разрешения от службы разрешений.
- **Свой язык программирования «Дубина»**: безопасный по построению. На нём нельзя написать вирус — нет сырых указателей, нет inline asm, нет FFI, нет рефлексии, нет ambient authority.
- **Динамическая разрядность чисел**: тип `Число` физически занимает столько бит, сколько нужно для текущего значения, округлённо до степени двойки. Расширяется автоматически при росте.
- **Архитектуры**: x86_64 и aarch64 (ARMv8).
- **Свой загрузчик** — Legacy BIOS (MBR + Stage2) и UEFI.
- **Своя файловая система ДубФС** с журналированием, шифрованием AES-XTS, контрольными суммами BLAKE3, копированием при записи.
- **Тестирование**: всё проверяется в QEMU.

## Быстрый запуск

Нужны пакеты:
- `qemu-system-x86`, `qemu-system-arm` — эмуляция;
- `nasm`, `binutils` (для `objcopy`) — собственный загрузчик;
- `xorriso`, `mtools`, `grub-pc-bin` — только для альтернативного пути через GRUB;
- Rust nightly с `rust-src`, цели `x86_64-unknown-none` и `aarch64-unknown-none`.

```bash
# Запуск собственного загрузочного образа (свой MBR + Stage2 + ядро) в QEMU
make запуск

# Запуск через GRUB Multiboot2 ISO (для проверки совместимости)
make запуск-grub

# Сборка и запуск ядра aarch64 в QEMU virt
make запуск-aarch64

# Юнит-тесты компилятора и рантайма
make тесты
```

После загрузки на serial-порт идёт примерно такой вывод:

```
DubinaOS MBR: loading stage2...
MBR: stage2 loaded, jumping...
Stage2: hello, real mode 16bit
Stage2: A20 enabled
Stage2: kernel loaded at 0x10000, switching to PM32...

╔══════════════════════════════════════════════════╗
║              Д У Б И Н А   О С                   ║
║         Версия 0.1.0 — этап «Фундамент»          ║
╚══════════════════════════════════════════════════╝

[OK] Архитектура: x86_64 (long mode)
[OK] Идентификационное отображение 0..4 ГиБ установлено
[OK] GDT с 64-битным сегментом загружен
[ИНФО] Магия загрузчика: 0x00000000D0BA0BE5
[ИНФО] Загружено через собственный загрузчик ДубинаОС (MBR + Stage2)
```

Ровно до банера ядра проходит вся цепочка наших собственных компонентов:
**BIOS → MBR (наш, 512 байт) → Stage2 (наш, ~1 КиБ, real mode → protected mode)
→ ядро (наше, .code32, переходит в long mode и зовёт Rust).** GRUB не используется.

| Подсистема | Статус |
|---|---|
| Свой MBR (LBA-чтение через INT 13h) | работает, грузится в QEMU |
| Свой Stage2 (real mode → protected mode → ядро) | работает, грузится в QEMU |
| Ядро x86_64 (.code32 → long mode, GDT, paging 4 ГиБ) | работает, грузится в QEMU |
| Ядро aarch64 (QEMU virt, EL1, FP/SIMD) | работает, грузится в QEMU |
